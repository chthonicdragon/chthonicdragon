# Screenshots

Drop real EsotericaOS screenshots here with these exact filenames — the Featured Project section
picks them up automatically and falls back to a placeholder if a file is missing:

- `graph.png` — Personal knowledge graph (large, top-left slot)
- `umbra.png` — Umbra, the AI guide
- `tarot.png` — Tarot reading interface, with a spread already revealed

Capture from a desktop browser window on the English version of the site, at roughly a 16:10
aspect ratio (e.g. a ~1600×1000 window) so nothing gets cropped by the browser-frame mockup.
Recommended export size: 2400×1500, PNG or WebP, under ~400KB each. Leave the OS/browser chrome
out of the shot, just the app viewport.
